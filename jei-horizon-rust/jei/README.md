# Just Enough Items (Horizon native mod)

JEI is an item and recipe viewing mod for Minecraft, built from the ground up for stability and performance.

Translated from Java FABRIC mod format into Horizon native Rust mixins.

## Installation

1. Copy the mod bundle or extracted folder into your Horizon launcher native mods directory:
   ```sh
   horizon-launcher mods install jei
   ```
2. In the Horizon launcher, select Mods -> Just Enough Items -> Build.
3. Launch the game and configure options under Options -> Mods -> Just Enough Items.
