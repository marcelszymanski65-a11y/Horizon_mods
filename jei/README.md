# Just Enough Items (Horizon native mod)

JEI is an item and recipe viewing mod for Minecraft, built from the ground up for stability and performance.

Translated from Java FABRIC mod format into Horizon native Rust mixins.

## Installation

1. Copy the `jei-31.17.0.108.hnmod` file (or extracted `jei` folder) directly into your Horizon mods directory:
   - Windows: `%APPDATA%\horizon\horizon-mods\jei-31.17.0.108.hnmod`
   - Linux: `~/.local/share/horizon/horizon-mods/jei-31.17.0.108.hnmod`
2. Open the Horizon Launcher GUI.
3. Navigate to **Mods** -> find **Just Enough Items** -> click **Build**.
4. Launch the game and configure options under Options -> Mods -> Just Enough Items.
